# My Power BI Dashboard Portfolio

Data Nerds! This repository is a collection of Power BI dashboards I've developed. It tracks my journey in using Power BI, from foundational reports to advanced interactive analyses, all aimed at turning data into clear, actionable insights.

# # Featured Dashboards

## 📈 Olist E-Commerce Executive Analytics Dashboard
An executive-level data analytics framework engineered using a Star Schema data architecture to analyze Brazilian e-commerce operations. This system unifies dynamic filtering and user-interactive parameters to deliver immediate operational clarity.

🎯 **Key Performance Indicators (KPIs) Defined:**
* 💰 **Total Revenue / Gross Merchandise Value (GMV):** Tracks the macro-level financial health of the marketplace by calculating the total monetary value of all processed transactions.
* ⭐ **Customer Satisfaction Score (CSAT):** Evaluates operational quality and vendor performance by aggregating and averaging customer review ratings.
* 📦 **Order Fulfillment Rate & Lead Time:** Monitors supply chain efficiency by calculating the average duration from order placement to final customer delivery.

**Key Power BI Skills Utilized:**
* 🧠 **Advanced Data Modeling:** Engineered a comprehensive Star Schema data architecture to handle complex transactional operations efficiently.
* 🎛️ **Dynamic Field Parameters:** Implemented field parameters natively allowing executives to toggle customer satisfaction visuals between Count and Revenue metrics.
* 🗺️ **Geospatial & Trend Analysis:** Constructed custom chronological line charts for historical tracking alongside spatial tracking templates.
* ➡️ **Drill-Through Functionality:** Configured Page Drill-Through infrastructure to pass product filters seamlessly into deep-dive reports.

## 🛠️ Advanced Parameters & Field Control Dashboard
A dedicated project focused on dynamic user control frameworks in Power BI. Implements advanced parameters and field slicers to allow end-users to shift visual granularities, dimensions, and core calculation metrics seamlessly on the fly.

🎯 **Key Performance Indicators (KPIs) Defined:**
* 🔄 **Dynamic Metric Value:** A polymorphic KPI card that instantly recalculates and displays either Total Sales, Quantity Sold, or Profit Margin depending on user selection.
* ⏱️ **Time-Intelligence Variation:** Tracks performance fluctuations (e.g., Year-Over-Year or Month-Over-Month growth) dynamically across selected dimensions.

**Key Power BI Skills Utilized:**
* 🎚️ **Interactive Slicers & Parameters:** Developed dynamic parameters for immediate runtime alterations of active axes and metric scopes.
* 🎨 **User Experience (UX) Design:** Formulated highly fluid page interactions to declutter workspaces while maintaining key analytical capabilities.
* 🔍 **Advanced Filtering Configurations:** Structured custom filter logic to enable macro-to-micro structural switches dynamically.

## 💼 Data Science Jobs Analytics Dashboard
A comprehensive exploration into the 2024 global data science job market, analyzing compensation distributions, regional hiring trends, and technical skill frequencies.

🎯 **Key Performance Indicators (KPIs) Defined:**
* 💵 **Median Yearly Salary:** Represents the central tendency of global data roles compensation, providing a realistic baseline adjusted for extreme outliers.
* 📊 **Job Posting Volume:** Measures market demand by tracking the net frequency of open listings aggregated by job title, seniority, and location.
* 📈 **High-Demand Skill Penetration Rate:** Identifies the percentage frequency of specific technical requirements (e.g., Python, SQL, Power BI) across all active postings.

**Key Power BI Skills Utilized:**
* 🧼 **Data Power Query (ETL):** Handled advanced data cleaning, missing value logic, and tabular formatting across flat data structures.
* 📊 **Core Charts & KPI Indicators:** Utilized column, line, and localized indicator card blocks to cleanly map global tracking trends.
* 🗺️ **Geospatial Analysis:** Leveraged map visualizers to represent distribution rates across global technical job boards.
